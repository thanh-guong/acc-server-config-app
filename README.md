# AccServerConfigApp

Welcome to ACC Server Config, an helper application for Assetto Corsa Competizione dedicated servers configuration.

This application enables users to set up Assetto Corsa Competizione **dedicated servers JSON configuration files**.

Actually work in progress, so if you find any bug please report them!

## Development section

This section contains detail for **developers**.

### Running in local environment

To start a **local** development **server**, run:

```bash
ng serve
```
### Technologies in use

- Angular 21
- Angular Material 21
